PIPELINE

Signatures catch the known.
This catches what doesn't have a name yet.

Your existing IDS stack stays exactly where it is. Driftnet only ever sees what gets past it.

01 · existing stack

Suricata / Snort

Signature and rule-based detection on raw traffic, unchanged from your current setup.

02 · existing stack

Zeek / Wazuh

Protocol logging and host-level correlation, feeding the same alert pipeline you already trust.

03 · new layer

Flow scoring

Traffic that clears the rule layer is converted to flow features and scored by an autoencoder calibrated on your benign baseline.

04 · output

Anomaly report

Above-threshold flows get a severity score and context — for a human to triage, not a rule to silently auto-block.
